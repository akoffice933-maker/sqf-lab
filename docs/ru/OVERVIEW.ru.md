# Обзор проекта (RU)

`sqf-lab` — это **лаборатория методов поиска скаляра на `secp256k1`** с упором
на воспроизводимость, а не на обещания.

## Что решается

Задача: по открытому ключу `P = k·G` и известному интервалу `[a, b]` найти `k`.
Классические методы — BSGS (таблица `√W`, память `√W`) и кенгуру Полларда
(память ≈ `O(1)`/`O(D)`, время `~2√W`). Оба дают `O(√W)`; **ни один не ломает
экспоненту**. Всё, что можно улучшать — константу и профиль памяти.

## Что сделано в этом репозитории

1. **SQF (Symmetric Quartet Folding)** — BSGS с `±`-симметрией одновременно по
   «детской» (таблица `±r`) и «гигантской» (`±q`) осям, плюс зеркальная сборка
   таблицы (`mirror_multiples`), где одна инверсия поля даёт две точки.
   Замер: `0.94–1.14·√W` в Python и `1.04–1.62·√W` в C++ на слепых ключах.
2. **Честный стенд.** Секрет генерируется снаружи, решатель получает только
   `P` и `[a,b]`; счётчики инкрементируются внутри циклов; проверка ответа —
   после выхода из решателя. Сырые JSON лежат в `benchmarks/results/`.
3. **Реестр анти-дубликатов.** Аренда блоков строго после максимального
   выданного `end_k` под `BEGIN IMMEDIATE`; ключи хранятся как солёные отпечатки
   `blake2b`, а не в открытом виде. Есть эталонный HTTP-API и e2e-тест.
4. **Реконструкция `path-to-greatness-3ltc`.** Проверяемые декодеры подсказок
   2, 3, 8 и реестр сегментов: 37 373 278 038 проверенных пар, 0 попаданий.
   Ключ неизвестен — и это зафиксировано, а не замаскировано.
5. **«Морской бой в одном квадрате»** — модель расписания (клетка = точный
   интервал скаляров) и аудит «ранений» с базовой линией дня рождения, чтобы
   не путать случайное совпадение битов с прогрессом.

## Быстрый старт

```bash
python3 -m pip install -e ".[dev]"
make test          # 60 тестов
make native        # C++ движки
make bench-native  # замер нативных решателей
python3 -m sqflab p2g clue2
```

## Чего здесь нет и не будет

* Рабочих эксплойтов против живых чужих сервисов.
* Утверждений о сложности ниже `√W`.
* «Складывания» интервала вокруг известного ключа — это тавтология.
